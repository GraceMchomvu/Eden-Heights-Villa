# Eden Heights Villa

Website for **Eden Heights Villa** — a private Airbnb home in Kiserian, Mijogoroni, Arusha, Tanzania.

## Preview locally

Open `index.html` in a browser, or serve the folder:

```bash
npx http-server -p 5500 -c-1 .
```

Then visit http://localhost:5500
